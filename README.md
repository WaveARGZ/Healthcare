# BodyMake Support App v2

## 概要
HTML / CSS / JavaScriptだけで動く、筋トレ・ダイエットサポートアプリの簡易プロトタイプです。

## 今回の画面遷移
1. プロフィール入力
   - 身長
   - 体重
   - 性別
   - 年齢
   - 目標
2. 体型写真アップロード
3. AIで生成した理想体型を選択する画面
   - 絞った体型
   - 筋肥大した体型
   - 健康的に維持する体型
4. ホーム画面
5. ホームから以下へ移動
   - 食事管理ページ
   - 筋トレ記録ページ
   - ダッシュボード
   - 掲示板

## 注意
この版では、Node.js、データベース、本物のAI APIは使っていません。

- AI画像生成はモックです
- データはlocalStorageに保存されます
- DBやログイン機能はまだありません
- `index.html` をブラウザで開くだけで動きます

## VS Codeでの動かし方
1. このフォルダをVS Codeで開く
2. ターミナルで以下を実行

```bash
dir
```

3. `index.html` が表示されたら以下を実行

```bash
start index.html
```

## ファイル構成
```text
bodymake-simple-app-v2
├── index.html
├── style.css
├── script.js
└── README.md
```

## それぞれの役割
- `index.html`：画面の構造
- `style.css`：デザイン
- `script.js`：画面遷移、入力保存、掲示板、フィードバック処理
- `README.md`：説明

## v0.5 — 種目ピッカー（EXERCISE LIBRARY）

- `exercises.js`：筋トレ種目マスターDB（**295種目**、部位×サブカテゴリ×器具×対象筋肉）
- 筋トレ記録画面を刷新：
  - 検索バー（トレーニングを検索）／部位フィルタチップ／頻度順・名前順ソート
  - 各行に**人体図ピクトグラム（対象筋肉をハイライト）**＋「部位｜種目名」＋記録頻度＋ブックマーク＋詳細(i)
  - チェックで複数選択 →「トレーニングを追加する」→ 記録待ちカードで重量(任意)×回数×セット（有酸素は分）を入力して記録
  - 検索ヒットなし時はカスタム種目として追加可能
- 詳細モーダル：人体図＋対象筋肉チップ＋フォーム解説＋**YouTubeフォーム動画検索／Google検索への外部リンク**
- ブックマークと記録頻度はアカウントごとに保存
- 注意：市販アプリのイラスト素材は著作権上使用できないため、図は自作SVG人体図で代替
